Confidențialitate și limite

Ce stocăm

Profilurile, proiectele și notele sunt salvate doar în IndexedDB-ul browserului folosit. Proiectele sunt criptate cu AES-GCM folosind o cheie derivată din parola introdusă de utilizator. Parola și cheia nu sunt trimise serverului. Exportul este criptat și este inițiat numai de utilizator.

Ce primește serverul

Serverul livrează exclusiv fișierele statice necesare aplicației; aplicația nu transmite textul proiectelor sau parole. Furnizorul de găzduire poate procesa metadate tehnice ale solicitărilor web, precum adresa IP, data, URL-ul fișierului și agentul browserului. Vezi politicile de confidențialitate ale furnizorului de găzduire.

Ce NU oferă

Nu există recuperarea parolei, conturi cloud, sincronizare automată, servicii AI, backup pe server ori colaborare între utilizatori. Nu putem recupera datele în cazul pierderii parolei sau al ștergerii stocării browserului.

Cine poate testa

Acest pilot este destinat adulților, folosind numai date fictive sau fără caracter sensibil. Nu introduce date personale ale minorilor, elevilor sau ale altor persoane. Nu este un instrument școlar aprobat.

Ștergere

Ștergerea datelor site-ului din browser elimină seifurile locale. Pentru o copie de rezervă, folosește exportul criptat înainte de ștergere. Exportul nu este trimis operatorului.
